# User Stories: AXIVON LEARN

**Title:** Platform User Stories (Agile Backlog)  
**Purpose:** User-centric agile requirements for Visitors, Learners, and Administrators.  
**Status:** Approved Requirements  
**Owner:** Technical Project Lead  
**Last Updated:** 2026-10-31  

---

## 1. Visitor Stories

* **US-VIS-01:** *As a visitor*, I want to browse published courses without creating an account, so that I can evaluate whether the curriculum fits my learning goals.
* **US-VIS-02:** *As a visitor*, I want to view a course's syllabus and prerequisites, so that I can prepare the required foundation before enrolling.
* **US-VIS-03:** *As a visitor*, I want to register for a free account, so that my course enrollments and progress can be saved.

---

## 2. Learner Stories

* **US-LRN-01:** *As an authenticated learner*, I want to enroll in a course with a single click, so that it appears on my personalized dashboard.
* **US-LRN-02:** *As an authenticated learner*, I want to watch lesson videos and read reference notes in a distraction-free player, so that I can learn effectively.
* **US-LRN-03:** *As an authenticated learner*, I want to mark lessons complete, so that I can track my syllabus completion percentage.
* **US-LRN-04:** *As an authenticated learner*, I want to attempt multiple-choice quizzes after completing a module, so that I can evaluate my understanding and receive instant scoring.
* **US-LRN-05:** *As a returning learner*, I want to click "Continue Learning" on my dashboard, so that I immediately jump to my next unfinished lesson.

---

## 3. Administrator Stories

* **US-ADM-01:** *As an administrator*, I want to access a protected CMS panel, so that I can author and manage course curriculum without touching source code.
* **US-ADM-02:** *As an administrator*, I want to create draft courses and preview them before publishing, so that only quality, reviewed content appears publicly.
* **US-ADM-03:** *As an administrator*, I want to create quiz questions with four options and mark the correct answer, so that assessments grade automatically on the server.
* **US-ADM-04:** *As an administrator*, I want to view platform overview metrics (total courses, published count, categories), so that I understand platform activity.
