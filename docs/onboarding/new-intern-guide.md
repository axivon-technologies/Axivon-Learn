## 1. Welcome to AXIVON LEARN!
Tagline: **Learn. Build. Grow.**

### Day 1 Checklist:
- [ ] Read `README.md` and `docs/project/project-overview.md`.
- [ ] Verify Node.js v22 and npm installed: `node -v` and `npm -v`.
- [ ] Run `npm install` and verify `npm test` passes.
- [ ] Read `docs/onboarding/team-ownership.md` and `docs/onboarding/development-workflow.md`.
- [ ] Confirm your assigned Task ID before creating any feature branch.
