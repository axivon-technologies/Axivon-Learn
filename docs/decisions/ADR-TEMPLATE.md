# ADR-000: Architecture Decision Record Template

**Title:** Short descriptive title of the architectural decision  
**Status:** Proposed | Accepted | Deprecated | Superseded  
**Decision ID:** ADR-XXX  
**Date:** YYYY-MM-DD  
**Owner:** Engineer / Architect Name  

---

## 1. Context
What is the context, requirement, or technical challenge we are addressing?

## 2. Options Considered
- Option A: (e.g. Next.js App Router)
- Option B: (e.g. React + Vite SPA)
- Option C: (e.g. Remix)

## 3. Decision
State the chosen option clearly.

## 4. Rationale & Consequences
Why was this option selected? What are the positive trade-offs and operational implications?
