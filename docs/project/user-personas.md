# User Personas: AXIVON LEARN

**Title:** Target User Personas & Behavioral Profiles  
**Purpose:** Defines primary user archetypes, their pain points, and how AXIVON LEARN responds to their needs.  
**Status:** Approved Requirements  
**Owner:** UI/UX Lead & Product Manager  
**Last Updated:** 2026-10-31  

---

## 1. Persona 1: The College Beginner (Aarav)

* **Background:** 2nd-year computer science student wanting to learn AI & Machine Learning.
* **Goals:**
  - Understand where to begin without drowning in complex calculus.
  - Follow an ordered, trustworthy roadmap.
  - Test his knowledge before jumping to the next topic.
* **Frustrations:**
  - Random YouTube playlists that stop midway.
  - Tutorials assuming pre-existing advanced knowledge.
* **AXIVON LEARN Solution:**
  - AI & Machine Learning Foundations path with explicit prerequisites and sequential syllabus.
  - Micro-quizzes after each lesson to validate comprehension.

---

## 2. Persona 2: The Self-Directed Web Developer (Priya)

* **Background:** Early-career developer transitioning from basic HTML/CSS to modern Full Stack engineering.
* **Goals:**
  - Master TypeScript, React, Node.js, and MongoDB in a production-like monorepo pattern.
  - Build real-world portfolio projects.
* **Frustrations:**
  - Outdated tutorials mixing disparate JavaScript versions and incompatible dependencies.
  - No way to track which parts of the syllabus have been completed across multiple devices.
* **AXIVON LEARN Solution:**
  - Full Stack Web Development path based on modern TypeScript and RESTful APIs.
  - Persistent learner dashboard tracking lesson completion and quiz scores.

---

## 3. Persona 3: The Axivon Content Administrator (Dev Lead / Trainer)

* **Background:** Senior engineer at Axivon Technologies responsible for intern training and curriculum.
* **Goals:**
  - Create, reorganize, and update course syllabi quickly.
  - Add quiz questions and verify learner progress without committing code changes.
* **Frustrations:**
  - Hardcoded courses requiring Git commits, pull requests, and redeployments for simple typo fixes.
* **AXIVON LEARN Solution:**
  - Dedicated, role-protected Admin CMS with intuitive forms for courses, modules, lessons, and quizzes.
