## 2. Release Milestones

### Release 1.0: One-Month MVP (Current Baseline)
- Public Catalog & Curated Learning Paths.
- Course syllabus accordion, outcomes, and prerequisites.
- User registration, login, and secure session management.
- Responsive lesson player with YouTube embeds and study notes.
- Lesson completion toggles and progress persistence.
- Multiple-choice quizzes with instant grading.
- Learner dashboard with "Continue Learning" shortcut.
- Admin CMS to manage courses, modules, lessons, and quizzes.
- Standardized `/api/v1/health` monitoring and structured logging.

### Release 1.1: Polish & Retention (Post-MVP)
- Full-text search across courses and lessons.
- Additional category and level filters.
- Learner bookmarks for rapid access.
- Interactive project library with GitHub repository link submission.
- Password reset and email notification workflows.
- Verifiable completion certificates (subject to verification criteria).

### Release 2.0: Platform Growth (Planned)
- Instructor/Creator portal with draft approval workflows.
- Discussion forums and Q&A threads with moderation tools.
- Commercial features: Paid courses, coupon codes, and invoicing.
- Cohort and organization access control.
- Detailed learning analytics and CSV reports for administrators.

### Release 3.0: Advanced Capabilities (Long-Term Vision)
- Live class scheduling and interactive webinars.
- AI-assisted doubt clarification with transparent limitations.
- Sandboxed browser-based coding environments (following formal security audit).
- Enterprise Single Sign-On (SSO) and team management.
